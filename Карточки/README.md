# Карточки для повторения

Здесь лежат карточки для Anki по истории 6 класса.

Файл [`История 6 класс — 25 основных карточек.txt`](<История 6 класс — 25 основных карточек.txt>) можно скачать и импортировать в Anki как текстовый файл.

## Что внутри

- 25 самых важных карточек по пройденным параграфам § 2–14.
- Формат: вопрос → ответ.
- Темы: даты, персонажи, понятия, причины событий и культура.
- Ответы короткие, чтобы их было удобно повторять.

## Как импортировать в Anki

1. Скачать TXT-файл.
2. Открыть Anki.
3. Выбрать `Файл` → `Импорт`.
4. Выбрать обычный тип карточки `Вопрос → Ответ` / `Basic`.
5. Проверить поля:
   - 1-е поле — вопрос;
   - 2-е поле — ответ;
   - 3-е поле — теги.

Файл уже содержит служебные строки Anki:

```text
#separator:Tab
#html:false
#tags column:3
#deck:История — 6 класс
```

Поэтому Anki должен сам понять, что поля разделены табуляцией, а третий столбец — это теги.
