## Правило для военных тем

Если параграф содержит войны, походы или сражения, к нему добавляется проверенная историческая карта. Карта должна показывать направления движения, стороны, ключевые места и легенду, а не служить украшением. Источник и лицензия фиксируются рядом с картой. В таймлайне карта дополняет описание события и открывается при наведении или выборе даты. Собственные маршруты, границы и расположение войск без источника не рисуются.

## Формулы

- **Византия:** Римское наследие + сильный император + торговля + христианство.
- **Франки:** объединили → защитили → расширили → разделили.
- **Европа IX–XI вв.:** нападения → объединение или раздробленность → новые государства.
- **Арабы:** единая вера → единое государство → завоевания.
- **Халифат:** огромная держава → распад на части → единая культура сохраняется.
- **Феодализм:** земля → служба и защита → сеньоры, вассалы, крестьяне.
- **Католическая Церковь:** иерархия + земли + десятина → большое влияние.
